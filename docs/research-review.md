# 研究应用：跨领域证据与缺口复核

本记录针对数据收集系统的可用性、测量和分析风险。方法论文支持有条件的设计选择，具体课题仍需内容审查、目标人群认知访谈和预试。软件回归使用合成参与者与合成响应，线上模型验收也是虚构回答，不提供实际信效度证据。

## 已补读和核对的资料

### LLM访谈与交互

[Wuttke 等，2025，AI Conversational Interviewing: Transforming Surveys with LLMs as Adaptive Interviewers](https://aclanthology.org/2025.latechclfl-1.17v1.pdf)，LaTeCH-CLfL 2025，179–204页。

阅读方法、结果、人工编码与讨论。原文实际收集6次人工、5次AI访谈，大学生课堂情境，政治主题，GPT-4 Turbo；两类访谈使用相同问卷，顺序与角色安排见原文。人工与AI都存在违反访谈指南的行为。AI较多漏掉对意外、含糊回答的追问，也有鼓励性评价。作者明确将其视为小样本可行性验证，提示改动提示词也可能改变行为。等待和语音技术问题影响体验，回答长度随输入模式变化，长回答不能直接等同于更高质量。

应用：固定已发布题目与计分关系，模型负责衔接与补充问题；保存实际引导语及模型生成题目；中性承接，避免评价答案和提供答案暗示。仍需对本项目实际模型、人群、语言和主题进行人工编码复核。

[Croes 与 Antheunis，36 Questions to Loving a Chatbot: Are People Willing to Self-Disclose to a Chatbot?](https://conversations2020.wordpress.com/wp-content/uploads/2021/02/conversations_2020_paper24_croes_preprint.pdf)，CONVERSATIONS 2020作者预印本。

阅读方法、测量及结果。实验150人，平均约22岁，主要为学生；随机分为聊天机器人、人与人文字聊天、面对面条件，使用相同9道问题。机器人是Flow.ai构建的系统，不是本项目的LLM。自我披露的直接条件效应未显著；感知匿名和信任的作用不同。该结果不能证明聊天一定更真实，也不能把感知匿名解释为系统实际匿名。

应用：如实呈现AI处理与研究者可访问数据的事实；不以虚构身份、权威、夸奖或保密承诺诱导披露。具体伦理与组织关系需由研究者审查。

### 心理学与调查回应偏差

[Bogner 与 Landrock，2016，Response Biases in Standardised Surveys](https://www.gesis.org/fileadmin/admin/Dateikatalog/pdf/guidelines/response_biases_standardized_surveys_bogner_landrock_2016.pdf)，GESIS Survey Guidelines，DOI 10.15465/gesis-sg_en_016。

已核对指南概述：偏差可能来自受访者、访谈情境、提问与选项顺序，包括社会赞许、默认同意、顺序效应与第三人在场影响。它是综合指南，不是本项目效果的独立试验。Krosnick（1991）原文PDF本轮提取失败，仅核对书目信息与摘要，不列为已精读全文。

应用：中性、单一概念的问题，按目标人群预试理解与回答过程；不把短答或跳过直接判断为疲劳或不合作。按需展示说明、允许修改和主动结束。当前仍需真实无障碍测试、认知访谈及不同数字熟练度群体的手机可用性测试。

### 统计学与数学

[Lakens，Sample Size Justification](https://lakens.github.io/statistical_inferences/08-samplesizejustification.html)，作者公开教材第8章；章节声明与其2022年论文主要相同。正式PDF本轮未成功提取，阅读本章资源约束与事前功效规划部分，核对全文目录与框架。论文DOI 10.1525/collabra.33267。

样本量论证应与估计精度、重要效应、决策和资源相关，不能把某个固定份数视为通用标准。放开系统默认份数上限不等于完成样本量规划；如做推断，停止规则也应由分析方案决定。

另已核对VanderWeele（2019）协变量选择、Altman与Royston（2006）连续变量二分损失，见 [research-evidence.md](./research-evidence.md)。

应用：每题说明用途和需要的精度，变量用途可以重叠；当前默认仅报告描述统计。加权、聚类稳健推断、多层模型、纵向分析、缺失机制与多重插补、多重比较、序贯检验均未自动实现。原始数据可导出供有明确设计依据的分析。

### 管理学与组织研究

Podsakoff等（2003）共同方法偏差综述已核对书目与摘要，尚未获得可精读全文；[2012年相关综述](https://www.annualreviews.org/content/journals/10.1146/annurev-psych-120710-100452)本轮仅获得摘要与出版信息。不能声称已严格执行全部原文建议。

需在具体研究设计中评估同一来源、同一时间点和相似题式引入的共同方法影响，员工与管理者的权力关系，以及团队内依赖。当前可把这些问题写入方案并保留相关数据，但尚不支持多来源联结、多个测量波次、团队层抽样或对应统计模型；单纯增加自报题无法代替这些设计。

### 非回应与敏感问题

Groves与Peytcheva（2008，DOI 10.1093/poq/nfn011）非回应偏差元分析、Tourangeau与Yan（2007，DOI 10.1037/0033-2909.133.5.859）敏感问题综述，本轮只核对书目和摘要/相关指南，未标为全文阅读。相关缺口需后续补齐原文与课题针对性证据。

系统能记录已开始访谈的跳过、未问和主动结束，但没有完整的邀请分母或未参与者资料，不能据此计算总体响应率或自动修复选择偏差。缺失保存为缺失，不由LLM补造。

## 覆盖与验证矩阵

| 领域 | 当前落实 | 尚待验证或实现 |
| --- | --- | --- |
| UI/UX | daisyUI与Bits UI；逐题作答；按需说明；原值预填；修改；短链接；手机及键盘浏览器回归 | 真实读屏器、低数字熟练度、不同屏幕及高延迟情境 |
| 认知与心理 | 中性措辞要求；跳过、修改、结束；不按固定跳过数强制收尾 | 认知访谈、顺序效应、负担、社会赞许与参与者是否感到压力 |
| 测量 | 发布后题目版本一致；计分关系显式；原始回答保存；追问来源单独保留 | 专家内容审查、结构效度、信度、效标关系、跨组跨语言等值性 |
| LLM行为 | 结构校验；无法直接修改参与者记录；实际题目与引导留痕；错误回退可追溯 | 独立人工编码诱导、错误归因、漏问、重复与越界；攻击性/含糊输入试访 |
| 数学与统计 | 有效n、缺失、分布、均值、样本标准差；取消默认推断区间 | 抽样设计、样本量理由、停止规则、聚类、权重、非随机缺失、纵向和因果分析 |
| 管理与组织 | 方案审查同源自报、团队依赖和权力关系；实际招募背景由发起者填写 | 多来源/多时点设计、招募独立性、组织权限及成员实际安全感 |
| 信任与社会影响 | 真实披露AI处理和数据用途；主动结束及撤回入口；不承诺无法保证的匿名 | 场景下的权威暗示、过度信任、奖励影响与知情理解 |

## 发起研究者应提供什么

发起者提供课题、目标对象、研究用途、联系渠道和保存安排；可补充实际招募渠道与参与条件。用途合并为一项，说明研究结果的用途与回答的使用安排，同时供方案设计与参与说明使用。未知设计条件保留为待确认问题。Agent负责提出有来源依据的方案、题目用途、估计时长及分析建议。表单校验只能确认格式，不能验证发起者陈述真实或保证设计有效。

## 建议的首次真实预试

先由熟悉主题与方法的人审查方案及来源适用性，再邀请目标人群进行认知访谈与实际操作。对完整访谈进行独立人工编码：题意是否理解一致、是否出现诱导或错误重述、是否漏掉关键解释、重复追问是否增加负担。同步检查每题缺失、修订、退出、等待及设备问题。

预试规模、可接受表现和修改标准应根据具体研究目的事先说明。模型、提示词、交互或题目发生变化后，应评估是否需要重新预试。高思考等级是调用设置，不是研究质量验证。
